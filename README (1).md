## 四、問答題個人回答

### 問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？
**回答：**
因為在 Python 中，`"4"` 是帶有引號的字串（`str`），而金額（應付總額）是數字型別（如 `float` 或 `int`）。
在 Python 裡面，字串和數字是不能直接做除法運算的（如果寫 `1220 / "4"` 會直接跳出型別錯誤的紅字）。因此，我們必須先用 `int()` 將 `"4"` 轉成整數 `4`，電腦才有辦法正確執行「應付總額 $\div$ 分攤人數」的除法算式。

---

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**回答：**
如果改變計算順序（先減折價券，再算服務費），第一組的計算過程與結果會變成：
1. 先扣折價券：$1,200 - 100 = 1,100$ 元
2. 再算 10% 服務費：$1,100 \times 0.10 = 110$ 元
3. 應付總額：$1,100 + 110 = 1,210$ 元

**為什麼和題目不同？**
因為題目規定的規則是「餐廳按原始餐費收取 10% 服務費，計算服務費後，再扣除折價券」。
餐廳的服務費通常是以本來的用餐消費金額（未折價前）來計算比例，折價券則是商家或平台給予的折扣優惠，兩者的計算基準不同。如果先扣折價券才算服務費，服務費的金額就會變少（從 120 元變成 110 元），這跟餐廳原本的計費邏輯不符。
